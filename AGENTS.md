# AGENTS.md

The operating rules for any AI coding agent working on this repository are in [`CLAUDE.md`](CLAUDE.md). Read it first, then the specification in `docs/spec/` (`README.md` for the index).

Short version: the memory/performance budgets are hard requirements; terminal correctness and "never panic" come first; follow the clean-code, SOLID, Git and testing rules; verify dependency versions on crates.io; work package by package (`docs/12`); keep `PROGRESS.md` honest.
