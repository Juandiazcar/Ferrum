# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full, by reference, as its code of conduct. It applies in all project spaces: the repository,
issues, pull requests and discussions.

## Enforcement

Report unacceptable behavior privately through a
[GitHub security advisory](https://github.com/Juandiazcar/Ferrum/security/advisories/new) or by
contacting the maintainer, [@Juandiazcar](https://github.com/Juandiazcar), through GitHub. Reports
are handled confidentially, and the maintainer applies the enforcement guidelines of the Covenant.
