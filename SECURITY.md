# Security policy

## Supported versions

The latest minor release. Ferrum is pre-alpha and has no release yet.

## Reporting a vulnerability

Report privately through
[GitHub Security Advisories](https://github.com/Juandiazcar/Ferrum/security/advisories/new). Do not
open a public issue for a vulnerability.

- Acknowledgment within 72 hours.
- Fix targets: critical within 7 days, high within 30 days.
- Coordinated disclosure: the advisory is published together with the patched release.

The threat model and hardening rules are in
[`docs/spec/docs/10-security-and-privacy.md`](docs/spec/docs/10-security-and-privacy.md).
