# assets/icons

Application icons in every size and format plus the UI glyph set. The brand source icons already live in `assets/brand/` (SVG and PNG); they are not moved. This directory receives the generated platform icon formats (ico, icns, sized PNGs) and the UI glyphs.

**Filled by:** WP-08 (UI glyph set) and WP-18 (platform icon formats).
