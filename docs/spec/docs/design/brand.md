# Brand and visual tokens

Source files: `assets/brand/`. Logo approved by the maintainer on 2026-11-20 (Q-15 resolved).

## Logo
- App icon: `assets/brand/ferrum-icon.svg` (rounded square #16191D-ish dark, rust "F" built from three rectangles, light block cursor).
- Mono mark: `assets/brand/ferrum-mark-mono.svg` (`currentColor`, cursor at 55% opacity) for tray, favicon and monochrome use.
- PNG sizes 16–1024 in `assets/brand/png/`. Minimum rendered size 16 px; the cursor block must stay visible.
- Do not outline, add gradients to the F, rotate, or recolor the cursor.

## Wordmark
Lowercase `ferrum`, JetBrains Mono ExtraBold (800), letter-spacing -0.01em to -0.02em.

## Typography
JetBrains Mono (variable) everywhere. Hierarchy by weight: 800 wordmark, 700 project names and headings, 600 active items, 500 sessions, 400 terminal text.

## Signature element
The status-bar memory ruler: 50 ticks, one per MB of the budget, filled rust up to current usage.
