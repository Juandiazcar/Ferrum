# 71|q|GL is still G0: plain / 1b 6e 71|ESC n q|LS2: line drawing

ESC * designates G2; it takes effect through a shift.

Reference: xterm ctlseqs: SCS. Terminal size: 20x6.

| hex | bytes | meaning |
|---|---|---|
| 1b 2a 30 | ESC * 0 | G2 = line drawing |
| 71 | q | GL is still G0: plain |
| 1b 6e 71 | ESC n q | LS2: line drawing |
