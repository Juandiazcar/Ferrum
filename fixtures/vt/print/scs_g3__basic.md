# 71|q|GL is still G0: plain / 1b 6f 71|ESC o q|LS3: line drawing

ESC + designates G3; it takes effect through a shift.

Reference: xterm ctlseqs: SCS. Terminal size: 20x6.

| hex | bytes | meaning |
|---|---|---|
| 1b 2b 30 | ESC + 0 | G3 = line drawing |
| 71 | q | GL is still G0: plain |
| 1b 6f 71 | ESC o q | LS3: line drawing |
