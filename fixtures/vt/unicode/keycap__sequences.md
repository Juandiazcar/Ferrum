# keycap / sequences

A keycap sequence (digit, VS16, U+20E3) is one cluster.

Reference: emoji-sequences (keycap). Terminal size: 20x6.

| hex | bytes | meaning |
|---|---|---|
| 31 ef b8 8f e2 83 a3 | 1 <ef> <b8> <8f> <e2> <83> <a3> | text |
| 61 | a | text |
| 23 ef b8 8f e2 83 a3 | # <ef> <b8> <8f> <e2> <83> <a3> | text |
| 62 | b | text |
